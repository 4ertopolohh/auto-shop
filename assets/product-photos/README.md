# Catalogue photographs

The demo uses local WebP copies of real product photography rather than vector drawings. `sources.json` records the source pages, original URLs and checksums. Additional gallery frames are explicitly labelled crops of the same source photograph, not additional camera angles.

Some demo photographs show a representative component from the same product family rather than the exact SKU/pack size. These are demonstration illustrations and must not be used to confirm fitment. Rights remain with the listed manufacturers/retailers; public accessibility is not a blanket commercial image licence. Obtain catalogue-feed/image permissions before commercial publication.
