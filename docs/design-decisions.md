# Согласованные решения

Название — «Крутящий момент». Сайт создаётся с нуля и работает локально. Публикация в интернет не запрошена. GitHub: `4ertopolohh/auto-shop`, ветка `main`, обычные коммиты и push.

Уточнение интерфейса: без надзаголовков секций; кнопки и ссылки-кнопки только текстовые, без стрелок, плюсов и декоративных иконок. Списки выбора, checkbox и загрузка файлов кастомные (включая Django Admin). Все кнопки имеют плавные hover/press эффекты, reduced motion сохраняется.

Страницы: главная, каталог, товар с галереей, корзина, оформление, доставка и оплата, о магазине, 404. Поиск по названию, бренду, артикулу и OEM. Фильтры по категории, бренду, марке/модели, цене, наличию. VIN-базы нет; применимость демонстрационная.

Без аккаунтов покупателей. Контактные поля демонстрационного заказа фиксированы вымышленными значениями. Сервер отвергает произвольные поля и определяет цену, наличие, доставку самостоятельно. Успех, отказ и отмена оплаты доступны для проверки. Повторные запросы идемпотентны. Склад не уменьшается от демонстрационных операций.

Excel `.xlsx`: шаблон, предпросмотр, ошибки, подтверждение, обновление по SKU, фото из ZIP. Характеристики и совместимость — JSON в колонках. Все строки проверяются до записи. Объём ограничен; файлы изображений декодируются и пересохраняются WebP.

Адаптеры СДЭК и ЮKassa подготовлены для будущей коммерческой сборки. Текущая сборка имеет неизменяемую из админки политику DEMO_SITE: реальные платежи, отправления и загрузка Метрики запрещены. Для коммерческого запуска нужны отдельная политика данных, реальные реквизиты, фискализация, подтверждение платежей и испытания с аккаунтами провайдеров.

Демо по умолчанию закрыто от индексации robots/meta. Есть sitemap и runtime SEO-настройки. Реальная индексация потребует доступного домена и серверного рендеринга/предрендеринга публичных страниц; локальная SPA не выдаётся за готовое коммерческое SEO-развёртывание.
